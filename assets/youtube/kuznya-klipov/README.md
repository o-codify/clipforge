# Кузня Клипов — оформление YouTube

Канал: https://www.youtube.com/@kuznyaklipov

Оформление создано 24 сентября 2026 года через встроенный инструмент ImageGen. CLI и сторонние генераторы не использовались. Полный набор промптов сохранён в [prompts.json](prompts.json).

## Готовые изображения

| Файл | Назначение | Размер |
| --- | --- | --- |
| [banner.png](banner.png) | Баннер канала | 1672 × 941 |
| [avatar.png](avatar.png) | Аватар с фоном для круглого кадрирования | 1254 × 1254 |
| [logo.png](logo.png) | Логотип на прозрачном фоне, водяной знак видео | 1254 × 1254 |

Фирменный знак — фиолетовая наковальня с вырезом в форме Play. Палитра: графитовый фон, фиолетовый и светлая типографика. Название и подпись баннера расположены в центральной области, видимой на разных устройствах; кадрирование проверено в предпросмотре YouTube Studio.

`banner-draft.png` — промежуточный вариант, не используется на канале.

## Опубликованные настройки

Баннер, аватар и логотип загружены в YouTube Studio. Для логотипа выбрано отображение на протяжении всего видео. Studio подтвердил: «Все изменения сохранены».
