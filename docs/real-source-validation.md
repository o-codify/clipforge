- Первый результат Rostik ошибочно получился без камеры: модель плохо видела
  маску на маленьком исходном лице. Этот результат архивирован.
- Следующая попытка нашла другое лицо во вложенном видео, которое смотрит
  стример. Она тоже архивирована. Теперь поиск ограничен найденной по эфиру
  областью постоянной камеры; старые результаты её поиска автоматически
  пересчитываются после изменения версии детектора.
- Повторный поиск увеличивает только область анализа, а не ширину камеры
  в оформлении. Используются парные ориентиры глаз, локальное увеличение,
  нормализация яркости и проверка коротких пропусков с двух соседних кадров.
- Исходный момент Rostik 6:39.84–7:13.66 получил 64/69 подтверждений. Конвейер
  сам нашёл непрерывный участок вокруг исходного пика 6:52.80, сократил края
  и повторно проверил получившиеся 16.4 секунды: 34/34. Неподтверждённые
  моменты пропускаются, затем проверяется ограниченный резерв кандидатов.
- Игра в обеих компоновках показывается целиком, с сохранением пропорций,

## Проверки

`apps/worker/test/real-source-validation.mjs` запускает общий обработчик:
не больше одного клипа на эфир в режиме разработки. Повторный запуск
с той же версией использует уже созданный результат.

- `workers/python/tests/verify_real_sources.py`: повторная проверка всех
  четырёх реальных исходников текущим детектором; прежний пропуск лица NS
  при повороте теперь 71/71; автоматическое сокращение момента с маской.
- Отдельный искусственный отрицательный тест убирает камеру ровно на одном
  кадре: отслеживание не выдаёт пустой блок за лицо. Он не представлен
  пользователю как реальный клип.
- `verify_camera_video.py`: три реальных отрезка Sany и отрицательные проверки
  отсутствующей, исчезнувшей, перемещённой и неподвижной камеры.
- Все четыре готовых файла полностью декодированы FFmpeg без ошибок;
  визуально проверены начало, середина и конец. Контактные листы:
  `data/reviews/actual-{streamer}.jpg`; сведения: `active-clips.json` рядом.
- Все четыре клипа проиграны в штатном браузерном проигрывателе до конца:
  `ended=true`, `readyState=4`, ошибок media нет.
- Интеграционная проверка каталога: 4 активных, 193 архивных; счётчики,
  списки, версии и старые адреса согласованы.

Это проверка четырёх эфиров, а не гарантия для любых масок и раскладок.
Камера анализируется примерно каждые полсекунды. Низкое разрешение исходной
веб-камеры Recrent остаётся заметным при увеличении; расшифровка жаргона
содержит ошибки. Автоматическая массовая нарезка и публикация выключены
режимом разработки.
