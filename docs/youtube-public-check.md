## Изменения, подготовленные локально

- Таблица статистики YouTube в разделе «Управление → Публикации»: стример с аватаркой, канал, фактическая видимость, просмотры, лайки, комментарии, ограничения и время обновления.
- Недоступный показатель сохраняется как отсутствие данных, а не как ноль.
- Публичная дата берётся из YouTube; смена видимости отражается при следующем сборе.
- Сбор сразу после успешной публичной загрузки; его ошибка не меняет успешный статус загрузки.
- После следующей локальной доработки проверка также выполняется для приватных загрузок; добавлены API проверки, очередь ручного обновления и [штатный клиент `pnpm cf`](platform-tools.md). Для обычных операций временные скрипты больше не используются.
- Отметки остановленного сборщика и устаревших данных. Постраничная выборка по 50 видео.
- Доступ только администратору; отключаемые каналы исключены. Разрешение на производные рейтинги не включалось.

Новый интерфейс и изменения сборщика **не развёрнуты на сервере**. Работающий установленный сборщик продолжает собирать базовые счётчики; расширенные сведения об ограничениях будут регулярно обновляться после отдельной выкладки подготовленного кода.
