# Постоянный каркас ClipForge

Проверено 24 сентября 2026 года в Chrome на локальном интерфейсе с рабочим API.

- Боковое меню, хедер, общая сессия, очередь заданий и помощник находятся в корневом каркасе приложения.
- Переходы между разделами используют Next Link. При ожидании страницы загрузка показывается только внутри основной области.
- Страницы и кнопки получают пользователя из общего контекста, а не вызывают `/api/auth/me` каждая отдельно.
- Выход и ответ API 401 сбрасывают локальную сессию. Изменение режима просмотра администратора пересоздаёт контекст заданий и содержимое страниц, чтобы данные разных областей доступа не смешивались.
- В помощнике остался чат. Переходы и клики вне чата не закрывают его; работают кнопка закрытия и Escape.

## Проверка

- TypeScript: `pnpm --filter @clipforge/web typecheck`, `pnpm --filter @clipforge/assistant typecheck` — успешно.
- Переходы: клипы, стримеры, игры, задания, настройки и возврат браузера назад. Заголовок и выбранный пункт меню обновляются, открытый чат и несохранённый текст сохраняются.
- Наблюдение Network во время серии Клипы → Стримеры → Игры: 0 запросов типа Document, 0 запросов `/api/auth/me`. Буфер событий не усечён.
- Выход через меню аккаунта приводит на форму входа. Возврат назад после выхода не открывает закрытое содержимое; форма входа появляется снова. Повторный вход работает.
- Экран 1366 × 768: обзор занимает высоту 768, документ не прокручивается по вертикали.
- Экран 390 × 844: постоянное компактное меню слева, единый хедер, чат помещается справа от меню; высота мобильного слайда учитывает хедер. Горизонтального переполнения документа нет.
- Проверочные черновики очищены, временный размер браузера сброшен.

Первое открытие изменённых модулей в Next dev сопровождалось Fast Refresh. Контроль переходов выполнен после завершения обновления кода, без дальнейших изменений файлов во время измерения.
