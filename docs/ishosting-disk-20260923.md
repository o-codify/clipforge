# Диск ishosting — проверка 23.09.2026

Проверено через SSH, без удаления или перезапуска сервисов. Раздел `/dev/sda1`
ext4: 20 GiB, занято около 16 GiB (84%), доступно 3.2 GiB.

| Категория | Размер | Пояснение |
| --- | ---: | --- |
| `/var/lib/containerd` | 7.7 GiB | 5.8 GiB распакованных слоёв + 1.9 GiB содержимого образов |
| `/usr` | 3.6 GiB | Система и установленные программы |
| `/var/log` | 1.7 GiB | atop 858 MiB, journal 761 MiB |
| `/var/lib/snapd` | 683 MiB | В том числе несколько ревизий snap |
| `/var/lib/docker` | 619 MiB | Преимущественно тома: 561 MiB; метаданные контейнеров 57 MiB |
| `/root/backups` | 424 MiB | В основном резервные копии сегодняшнего переноса |
| `/var/lib/apt/lists` | 315 MiB | Индексы пакетов |
| `/boot` | 268 MiB | Ядро и загрузочные файлы |

Это непересекающиеся основные категории, округлённые `du`; они не обязаны
в точности совпадать с `df` из-за метаданных и резервирования ext4.

`docker system df`: 27 образов, 21 используется, суммарно 8.093 GB в учёте Docker;
1.402 GB помечено reclaimable. Это другая оценка тех же образов, её нельзя
прибавлять к размеру containerd. Неиспользуемые: старый chazari-api, anime-site
latest (рабочий сайт закреплён на 2026.806.10), coolify-helper, старый sentinel,
один образ без тега, chazari/ningyotsukai. Helper может понадобиться для деплоя;
прежние образы могут служить для отката.

Наиболее крупные рабочие образы: coolify-realtime 998 MB, specification-hub
771 MB, Coolify 644 MB, family-todo-api 557 MB, family-todo-bot 533 MB.
Указанные размеры образов могут включать общие слои, простое сложение неточно.

Данные PostgreSQL приложений — около 510 MB, БД Coolify — 74 MB.
Неиспользуемые volumes занимают только около 120 KB, build cache к удалению —
около 8 MB. Массовое удаление томов или чистка build cache проблему не решат.

Возможное освобождение: до ~1.4 GB неиспользуемых образов плюс сокращение
истории atop/journal. Удаление здесь не выполнялось: пользователь запросил
диагностику причин. Дампам и рабочим томам очистка не требуется.
