# Проверка на разных стримах — 23.09.2026

Актуальная проверка: [четыре реальных автоматических результата](real-source-validation.md).

> Эти первые пробы устарели и убраны из каталога вместе с прежними 191 клипами.
> Ниже сохранена история проверки. Актуальная проверка запускается через
> `apps/worker/test/real-source-validation.mjs`: общий обработчик сам выбирает
> момент и камеру. Принудительный рендер без лица больше не используется.

Созданы три проверочных клипа. Автоматическая массовая нарезка остаётся выключенной.

| Стример | Прогон | Материал | Результат камеры |
|---|---|---|---|
| rostikfacekid | 20260923-192119-f69bd6 | Dota 2, момент выбран рабочим конвейером | 9/69 кадров: отдельный блок выключен |
| just_ns | 20260923-192313-3961ca | Dota 2, фиксированный отрезок 1:00:20–1:00:55 | 70/71: один пропуск, отдельный блок выключен |
| Recrent | 20260923-192342-d2bb10 | PUBG, фиксированный отрезок 2:00:20–2:00:55 | 71/71: отдельный блок включён |

NS и Recrent — проверка оформления, не качества автоматического выбора интересных моментов. Загружено по 80 секунд исходника (по 32.5 МБ), последовательно с лимитом 5 МБ/с. Расшифровка large-v3, batchSize=1. Проверены кадры начала, середины и конца всех трёх роликов; контактные листы находятся в data/reviews/*-review.png. Каждый клип открыт в штатном проигрывателе: readyState=4, ошибок media нет; NS воспроизведён до конца.

Наблюдения: высота игрового блока одинакова; текст помещается в кадре; лицо Recrent остаётся в выделенной области. Поиск лица нельзя считать завершённым: у NS единичный пропуск при видимой камере отключает панель на весь клип. Узкая исходная камера Recrent заметно теряет детализацию при увеличении; оценка границ по лицу захватывает немного фона, а остаток исходной камеры может оставаться у края игрового блока. Реальные маски на этих трёх эфирах не проверены. Расшифровка игрового жаргона содержит ошибки. Эти ограничения не подменяются успешным рендером.
